This project presents a comparative study of two deep learning architectures—Transformer (PatchTST-inspired) and CNN-LSTM—for automated ECG arrhythmia classification using the MIT-BIH Arrhythmia Database. The ECG signals were preprocessed through normalization, baseline wander removal, and bandpass filtering before heartbeat segmentation using R-peak annotations. The segmented heartbeats were mapped into the five AAMI heartbeat classes (N, S, V, F, and Q). Both models were trained and evaluated using the same dataset split and evaluation metrics to ensure a fair comparison. The Transformer and CNN-LSTM models each achieved approximately 98% classification accuracy on the test set, demonstrating their effectiveness in accurately detecting and classifying cardiac arrhythmias.
